# dsh-follow-until-screen · 智能滚动助手

让长回答自动滚到刚好铺满一屏就停下，把回答的第一行留在屏幕顶部，剩下的交给你自己往下读。

## 这个项目是做什么的

DSH 默认会自动滚到底部：长回答出现时，页面总是跟着往下滚，导致你刚读第一句内容就滑上去了。关掉自动滚动又会导致短回答无法即时显示。

本插件取了一个**中间路线**：

- **回答不满一屏时**：照常自动跟随，确保新内容始终可见；
- **回答刚好铺满一屏时**：页面停止滚动，开头稳定停在屏幕顶部附近；
- **回合结束后**：不再自动跳回最底，让你能安稳地阅读。

它不依赖任何其他插件，**该滚的时候滚，该停的时候停**。

## 快速开始

### 安装

1. 打开 DSH 的「插件」页，点击「添加插件」；
2. 输入插件地址并确认：

   ```text
   git+https://github.com/BitStandByYou/dsh-follow-until-screen.git#v0.2.0
   ```

3. 启用插件后，**必须刷新 Web 界面**（或重启 DSH）以加载客户端脚本。
