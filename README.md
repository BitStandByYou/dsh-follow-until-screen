# dsh-follow-until-screen · 回答满一屏就不再自动滚动

让长回答自动滚到刚好铺满一屏就停下，把回答的第一行留在屏幕顶部，剩下的交给你自己往下读。

---

## 这个项目解决什么问题

DSH 默认会自动滚到底部：回答在屏幕上出现或变长时，页面总是跟着往下滚。短回答这样很贴心，
长回答就很折磨——你刚想从第一句开始读，内容已经滑上去了；等回答结束，页面还停在最底，
又得手动滚回开头。

那直接关掉自动滚动行不行？也不行：回答还没铺满一屏时，你就可能看不到后续内容。

这个插件取中间路线：

- 回答**还没占满一屏**时，照常自动往下滚，新内容始终在视野内；
- 回答**刚好占满一屏**时，相当于你自己往上滑了一下，页面不再自动滚动；
- 之后回答继续出现，**页面保持不动**，开头稳定停在屏幕顶部附近；
- 回合结束后，也不会再跳回最底。

> 一句话：**该滚的时候滚，该停的时候停。**

插件只关心一件事：**这条回答在屏幕上到了哪个位置**。至于回答是一次性给出的，还是一段段出现的，
判定完全一样。所以它不依赖任何其他插件，装上就能用。

## 快速开始

### 前置条件

- DSH Desktop，Web 界面版本 `0.2.2-rc.1`（本插件按该版本的会话 DOM 编写）

> 如果你另外装了 `dsh-smooth-stream`（`0.7.0` 已验证），本插件会自动识别它接手滚动的情况，
> 避免重复推动页面；不装也完全不影响使用。

### 安装（推荐：从 GitHub 安装）

打开 DSH 的「插件」页，点「添加插件」，在输入框里粘贴下面这行地址并确认安装：

```text
git+https://github.com/BitStandByYou/dsh-follow-until-screen.git#v0.1.0
```

末尾的 `#v0.1.0` 是固定版本标签。想跟进最新提交可以改成 `#main`，
但上游改动可能带来兼容风险。

安装完成后：

1. 启用 `dsh-follow-until-screen`；
2. 刷新 Web 界面（或重启 DSH），让客户端 bundle 重新加载；
3. 发一条会超过一屏的长回答，观察页面在回答占满一屏后停止滚动。

### 用命令行安装

```bash
dsh plugin --profile desktop add "git+https://github.com/BitStandByYou/dsh-follow-until-screen.git#v0.1.0"
```

DSH Web 版把 `--profile desktop` 换成 `--profile web`。装完同样要刷新界面。

### 从本地目录安装（开发调试）

1. 克隆仓库：

   ```bash
   git clone https://github.com/BitStandByYou/dsh-follow-until-screen.git
   ```

2. 在「插件」页点「添加插件」，输入仓库根目录的**绝对路径**
   （即包含 `package.json` 的这一层）。
3. 启用 `dsh-follow-until-screen`，刷新 Web 界面。
